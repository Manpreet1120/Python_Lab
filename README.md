# Python Lab
A collection of practical Python projects built to explore programming concepts and real-world applications.

## Projects
### Digital Clock

A simple desktop clock built with **Python and Tkinter**.

**Key Features**

* Displays the current time, day, and date
* Updates automatically every second
* Simple graphical user interface

**Tools:** Python, Tkinter

### Face Detection

A real-time face detection application built with **Python and OpenCV**.

**Key Features**

* Captures video using the computer's camera
* Detects faces in real time
* Displays a bounding box around detected faces

**Tools:** Python, OpenCV, Haar Cascade Classifier

## Purpose

This repository contains Python projects created to build programming skills and explore practical applications of Python.
